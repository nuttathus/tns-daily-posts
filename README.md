# TNS Solar Media Studio - 30-Day Meta Planner

ระบบศูนย์รวมสื่อและแผนการตลาดโซลาร์เซลล์ 30 วัน สำหรับโปรโมทบน Facebook / Meta Business Suite

🌐 **เข้าชมออนไลน์ได้ที่:** [https://nuttathus.github.io/tns-daily-posts/](https://nuttathus.github.io/tns-daily-posts/)

## คุณสมบัติเด่น (Features)
- 📅 **30-Day Ready-to-Post Planner:** ครอบคลุมเนื้อหาทั้ง 30 วัน วางแผนล่วงหน้าได้ 1 เดือนเต็ม
- 🎨 **3D Photorealistic Visuals:** ภาพโปสเตอร์ 3 มิติความละเอียดสูง พร้อมฟอนต์ภาษาไทยจัดระดับสายตา คมชัดทุกรูป
- 📋 **One-Click Copy Caption:** ปุ่มคัดลอกแคปชั่นครบถ้วน ทั้ง Hook, สาระความรู้, จุดขาย, และ Hashtags
- 💾 **Instant Image Download:** บันทึกรูปภาพ 3D ไปใช้งานต่อได้ทันที
- 🗂️ **Category Filter & Tabs:** แบ่งหมวดหมู่การตลาดชัดเจน (แก้ข้อสงสัย, โปรโมชั่น, คุ้มค่าการลงทุน, นวัตกรรมเทคโนโลยี, มาตรฐานความปลอดภัย)
